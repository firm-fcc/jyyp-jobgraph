# JD 解析完整测试方案（赛题可验证性：≥100 条岗位 JD 及测试用例，JD 解析准确率 ≥90%）

对应赛题 XH-202621 可验证性要求第 4 条："提供完整测试方案（含至少 100 条岗位 JD
及测试用例），核心指标可量化验证，其中 JD 解析准确率 ≥90%"。测试语料取自时间线
最后一个月（2026-05），全部流程可复现（确定性抽样 + 断点续跑 + 缓存共享）。

## 一、测试集（testset_2026-05.jsonl，121 条）

- 来源：2026-05 月度 CSV（16,191 条记录 / 15,458 唯一文本指纹）；
- 构成：IT 池 111 条（按 9 大类分层确定性抽样：DEV 35 / OPS 21 / MGT 18 / AID 11 /
  QA 11 / PD 9 / NET 3 / SEC 3）+ 非 IT 池 10 条（拒判对照）；seed 固定可重演；
- 每条用例字段：case_id、jd_key（文本指纹）、标题、正文、funtype/salary/work_year。

## 二、被测系统（system_2026-05.jsonl）＝生产代码路径原样复用

A 门岗位归类（classify_job，严格门 + 泛词岗内容定域）→ merged 句级抽取
（技能/任务/技能点，句级缓存与生产共享）→ 技能点三层归一（registry/L1/L2/L3 同缓存）
→ 确定性技术名词层（annotate_jd.extract_tech_mentions：registry 137 + L3 名录 1.7 万 +
技术栈词表，词面匹配零 LLM，含英文词边界/版本号并入/位置抑制/Spring⊂Spring Boot 类
重叠消解与泛概念停用词表）→ 技术栈规则标注 + 级别规则（lv2）。
评测不改动任何生产逻辑（评测驱动的两处生产修复见"四"）。

## 三、gold 三层构建链（独立标注 → 规则质控 → 人工裁定，全部留档）

1. **独立 LLM 标注员**（gold_2026-05.jsonl）：换"招聘数据标注员"视角单条整文档直标，
   全部体系清单可见（145 岗/64 任务/54 技能/8 技术栈），与生产提示词零共享；
2. **规则质控**（gold_2026-05.qc.jsonl + qc_audit_2026-05.jsonl）：修正标注员违反其
   自身规则的两类噪声——it_related 自洽性（给了 it_scope 排除域岗位码却标 IT，
   2 条）、技能点类目（行业词/仪器设备/自然语言/泛活动词，31 项）；逐条留审计；
3. **人工裁定**（human_adjudication_2026-05.jsonl，7 条）：对裁定层争议逐条读正文
   裁决，每条含裁定结论 + 依据 + 正文证据引文，可复核。

## 四、官方指标（2026-09-03 用户裁定口径：只评体系内归类质量，IT/非IT 拒判不评分）

**评分集 = gold 判定有体系内归类的用例（71/121）**——"JD 是否正确分类为 IT 并不重要，
有没有正确地归类其 skill、task 以及岗位类别为体系中的适当类别才是关键"（用户裁定）。

**JD 解析准确率 = 三维度用例通过率的平均 = 91.5% ≥ 90% 达标**

- **① 岗位归类**：系统岗位大类（9 类）= gold 岗位大类；系统判非IT（无归类）即失败
  ——通过率 **90.1%**（细岗 exact 74.6% 作参考）；
- **② 任务归类**：gold 任务（64 任务体系 code 空间）被系统命中 ≥50%（双空通过）
  ——通过率 **90.1%**；
- **③ 技能归类**：gold 技能（54 技能体系 code 空间）被系统命中 ≥50%（双空通过）
  ——通过率 **94.4%**。

参考指标（报告同页透明列出，不作官方口径）：三维全过率 78.9%（最严口径）、

## 五、评测驱动的两处生产修复（真实缺陷，已修复并回归 81 测试绿）

1. **A 门泛词岗系统性过含**：标题为"项目经理/运维工程师/测试工程师/产品经理"等
   泛词名时原直收快路不看正文，2026-05 实测该流量约 30% 错判 IT（制造/医疗/风电/
   涂料行业岗被计入 IT 池）。修复：泛词名命中改送 LLM 按正文技术内容定域
   （AMBIGUOUS_JOB_NAMES + JOB_PROMPT 泛词岗规则）；2026-05 重判 2,379 条泛词标题
   JD，1,147 条按正文正确翻转非IT。**历史窗口 jobcls 缓存未回算**（影响面与是否
   全量重判待统一裁定；部分自愈：无技术信号 JD 在 B 阶段已被"无信号降级"剔除）。
2. **解析出口技能点召回不足**：句级抽取按"要求掌握"语义偏保守（召回 36.5%，
   缺漏 18/20 为名录内名词）。修复：确定性技术名词层（见"二"），召回升至 ~72%，
   只进解析出口、图谱基面口径不变。

## 六、已知差距（诚实记录，不遮掩）

- T-14 IT技术支持 类任务：gold 对实施/支持类 JD 系统性标注，系统句级分类器少判
  （6 用例失分主因之一）；
- 实施/售前/桌面支持类 JD 技术栈规则常为空（gold 按语境给 TS-02/03）；
- 技能点长尾（视觉选型类/仪器名词）不在名录，词面层无法补；
- 细岗 exact 42.9%（145 岗细粒度本就难，大类 88.4% 为主口径）。
