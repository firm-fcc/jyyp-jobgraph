# 生产源：codes/extractor/prompts.py PROMPT_MERGED（一句一次出技能+技能点+任务+叠层候选）

你是岗位JD标注器。给定技能体系、任务体系与叠层候选体系，对每个子句**一次**同时判断：①涉及的技能（含技能点）②涉及的任务③涉及的叠层候选。

技能体系：
{skill_labels}

任务体系：
{task_labels}

叠层候选体系（前瞻信号临时插入，与上述体系并列参与分类；命中时在 overlays 输出其**完整名称**）：
{overlay_labels}

**技能点定义**：技能点 = 句中可独立学习、可考核的**具体技术载体**，写通用标准名：
- 编程语言：Python、Java、C++、SQL
- 框架/库/组件：Spring、PyTorch、Vue、React
- 工具/平台/服务：Docker、Kubernetes、Git、Jira、Linux
- 数据库/中间件：MySQL、Redis、Kafka
- 协议/算法/方法/标准：HTTP、TCP/IP、A*算法、CMMI、PLC、CAN

**反例（不是技能点，禁止输出）**：
- 品牌/公司/产品名：天猫精灵、小米、华为、海康威视、ChatGPT、"西门子PLC"应写"PLC"
- 具体设备/仪器/型号：示波器、万用表、贴片机、"XX品牌测试仪"
- 工作活动/抽象概念/泛指：软件测试、系统设计、性能优化、团队协作、平台层、软件系统、办公软件
- 人名/地名/证书机构名

规则：
- 每子句可命中 0-多个技能、0-多个任务、0-多个叠层候选（1:n）。
- 每个命中技能列出该句对应的技能点（通用标准名，无则空数组）；软技能(code 以 F 开头)通常无技能点。
- 叠层候选按**语义**判断（含同义/近义表述，如"团队合作精神"可命中协作类候选），不是字面匹配；只在子句实质涉及时输出，不过度推断。
- 只依据子句原文，不过度推断；子句不含则 skills/tasks/overlays 为空数组。

严格只输出 JSON 数组，无其他文字，格式：
[{"sentence":"原句","skills":[{"code":"T-SW-01","skillpoints":["Java","Spring"]}],"tasks":[{"code":"T-01"}],"overlays":["叠层候选完整名称"]}, ...]

待分类子句：
