# 前端单元测试

独立的测试工作区，依赖与配置自成一份，不改动 `frontend/package.json` 与
`frontend/package-lock.json`，因而不影响既有的构建与发布流程。

## 运行

```bash
cd frontend/tests
npm install
npm run test              # 仅运行用例
npm run test:coverage     # 运行用例并生成覆盖率报告
```

Windows 下可直接执行 `RUN_FRONTEND_TESTS.bat`，其余平台可执行 `./run_coverage.sh`，
两者均在依赖缺失时先行安装。测试只依赖本目录的 `node_modules`，无须先安装 `frontend/`
的依赖。

覆盖率报告输出至 `frontend/tests/coverage/`，其中 `index.html` 为逐文件的可视报告，
`coverage-summary.json` 为汇总数据。本目录下的 `coverage-summary.json` 与
`coverage-report.md` 是最近一次完整运行的留档。

## 结果

16 个测试文件、98 个用例，全部通过。

| 指标 | 覆盖 / 总计 | 比例 |
|---|---:|---:|
| 语句 | 4,136 / 4,570 | 90.5% |
| 行 | 4,136 / 4,570 | 90.5% |
| 函数 | 211 / 235 | 89.8% |
| 分支 | 1,137 / 1,469 | 77.4% |

四项门槛统一设为 60%，配置于 `vitest.config.ts`。任一项低于门槛时
`npm run test:coverage` 以非零状态退出。

## 覆盖范围

测试按“核心逻辑深测、主要能力面触达”组织：

- 工具函数：时间与数值格式化、确定性伪随机、SVG 几何计算；
- 人岗匹配演示链路：简历技能向量、岗位向量、五维综合匹配、相似岗位与投影；
- 人岗匹配实测链路：差距明细、建议归纳、学习路径、证据归并、候选人摘要；
- 实测派生层：能力向量、岗位相似度、覆盖率、简历分段；
- 简历真实性核验与经历关联；
- 数据层：岗位画像、岗位空间、职业探索与 JobViz 取数；
- API：成功响应、HTTP 错误、非 JSON 错误、请求体与查询参数；
- Hooks：后端会话状态、尺寸观测、缩放与平移；
- 组件与页面：公共组件、导航搜索、封面页的渲染检查。

覆盖率分母限于可作单元测试的执行逻辑。大型页面布局、纯视觉 SVG 图元与算法侧数据的
适配文件不计入分母，此类代码的正确性依赖端到端与视觉回归手段判定，以 DOM 断言堆砌
覆盖数字并不构成有效验证。分母的具体清单见 `vitest.config.ts` 的 `coverage.include`。

## 配置说明

`vitest.config.ts` 以 `frontend/` 为根，使被测源码按其自身的相对路径解析；React 及路由
库经别名统一指向本目录的依赖，避免同一份库被解析为两个实例。覆盖率插件同样装在本目录，
而 Vite 的模块解析以根目录为基准、不向下查找子目录的 `node_modules`，故亦按绝对路径
登记别名。
