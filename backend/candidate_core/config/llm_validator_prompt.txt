任务：根据简历原文，从候选能力中选择有明确证据支持的能力。

严格要求：
1. 只能选择候选能力列表中已经存在的能力；
2. ability 字段必须完全复制候选能力名称，不得改写；
3. 禁止新增任何能力；
4. 禁止输出 Python编程、PyTorch框架、Redis使用、MySQL使用、Linux操作等工具使用类表达；
5. 仅出现工具名称，不能自动推断工程部署、模型部署、数据库设计或项目开发；
6. source_sentence 必须是简历原文中的连续文本；
7. 没有充分证据的候选能力必须删除；
8. added 必须始终为空数组；
9. 只输出合法 JSON，不要解释。

输出格式：
{
  "approved": [
    {
      "ability": "必须与候选能力名称完全一致",
      "source_sentence": "简历原文证据句",
      "confidence": 0.90
    }
  ],
  "added": []
}
